MCP-серверы за шлюзом

Список — из реестра шлюза ключом активного токена (GET /v1/mcp/server): шлюз отдаёт только разрешённые ключу серверы. Каждый смонтированный сервер = строка dsh-mcp-client, streamable-http, url <gateway>/<server>/mcp, заголовок Authorization: Bearer <ключ токена>.

Токены доступа и их ключи

Токен доступа = LiteLLM-ключ: права на MCP-серверы и модели определяет шлюз (чужой сервер → пустой tools/list, чужая модель → 403). Каталог моделей = ответ GET /v1/models этим ключом. Поле write-only. «*» — сервер открыт целиком, иначе точечный allowlist raw-имён тулзов шлюза.

Модели под активным токеном

Источник правды — ключ активного токена: список получен запросом GET /v1/models и реально отдаётся каталогом session/modelCatalog. Модель вне списка шлюз отклонит (403), поэтому при переключении токена модель по умолчанию автоматически переставляется на доступную.

Диагностика гейтов (живой реестр)

visibleMcp у каждого живого агента — то, что реально отдаётся агенту из ctx.tools.schemas(scope). Модели — из ctx.llm.listProviders() (тот же путь, что session/modelCatalog).
